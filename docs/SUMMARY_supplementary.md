# Darts 补充实验汇总(3090)—— 2026-07-15

> 目的:在主表 MSL/SwaT/WADI(A100)之外,补泛化性(SMD/PSM)、seed 方差、方案B外推、效率、跨卡口径。全部 3090 单卡,与主表口径一致。

## 一、五数据集泛化全景(Darts threshold-free AUROC)
| 数据集 | 性质 | 最优头 | Darts AUROC | 卡 |
|---|---|---|---|---|
| SwaT | 周期强耦合控制 | VAE重构 | 0.838 | A100 |
| WADI | 118维高维控制 | VAE重构 | 0.744 | A100 |
| **SMD** | 服务器遥测(28机) | **预测** | **0.739±0.118** | 3090(新) |
| MSL | 事件驱动遥测 | 预测 | 0.666 | A100 |
| PSM | 服务器遥测 | VAE | 0.573 | 3090(新) |

- 泛化性成立:SMD 0.739(28机稳健分布),Darts 在新数据集有效。
- PSM 弱case(0.57,高异常占比点异常,预测/重构类普遍偏弱),如实报告。

## 二、范式规律(核心发现,外推到5数据集)
"最优检测头由数据性质先验决定":周期/高维控制系统→VAE重构(SwaT/WADI);事件驱动/遥测→预测(MSL/SMD)。SMD 新验证:预测头0.739>VAE0.705,与MSL一致。

## 三、方案B无泄露选头 外推成立
仅用训练数据注入合成异常构造验证集选头(零test泄露):
- SMD synth: 预测0.919>VAE0.832 → 选预测 = 真实最优 ✅
- PSM synth: VAE0.865>预测0.840 → 选VAE = 真实最优 ✅
→ "检测头可无泄露先验选出"从3数据集外推到5,闭环。

## 四、Seed 稳定性(3090, seed 42/43/44)
PSM预测0.572±0.029/VAE0.576±0.009;SMD 6机跨seed std 中位0.013-0.018,最大0.028。种子波动量级 0.013–0.029。

## 五、效率(同卡3090)
- **参数量 ~0.78M 且与维度无关**(节点权重共享,WADI 118维同样0.78M)→轻量、适配高维。峰值显存~2.9GB。
- 训练速度中游:MSL每epoch~87s,与DAGMM/USAD/OmniAnomaly同档,快于MAD-GAN,慢于TranAD。不宣称速度领先(诚实)。

## 六、跨卡口径
3090 vs A100 同config/data/seed的MSL差 ~0.026,与seed噪声(0.013-0.029)同量级。口径:每数据集单卡自洽、表内不跨卡比(MSL/SwaT/WADI→A100,SMD/PSM→3090);跨卡差在随机波动内,为稳妥仍单卡。详见 cross_card_check.md。

## 七、数据修正记录(踩坑存档)
1. cuda:0=3090(cuda:1=3060Ti 8G会OOM,PyTorch设备序≠nvidia-smi序)。
2. SMD旧副本label错位5×→改用IMDiffusion清洁源28台;full-res 28k撑爆窗口图O(num_windows²)→mean-pool下采样4×到~6k(与SwaT/WADI下采样口径一致)。
3. PSM下采样18×到train7360/test4880。
4. 磁盘/home共享盘曾100%满→删.params检查点+worker加每job省盘清理(只留epoch_0.1_lr_baseline)。

## 八、论文可用点
- 泛化性:5数据集,Darts在新增SMD领先/有效,规律复现。
- 方法论闭环:范式规律 + 方案B无泄露选头,均外推到新数据集。
- 轻量:0.78M参数维度无关,适配高维。
- 诚实边界:PSM弱、跨卡差、单卡口径、下采样,全部披露。
